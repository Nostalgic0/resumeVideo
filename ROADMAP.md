# Roadmap

## v0.2.0 (Next)

- Automated download of ffmpeg and whisper-cli on first launch
- Whisper model download from within the app
- Better onboarding experience for new users
- More UI languages (German, Italian, Japanese, Korean, Chinese)

## v0.3.0

- Unit and integration tests
- Drag-and-drop improvements
- Trimming: ability to select start/end time before processing
- Ask questions about any saved summary (chat)

## v0.4.0

- Full macOS packaging and code signing
- Full Windows packaging with auto-update
- Linux AppImage packaging
- Release automation via GitHub Actions

## v1.0.0

- Stable API for custom AI provider adapters
- Batch processing multiple videos
- Custom summary templates
- Plugin system for output formats
- Accessibility review and improvements

## Ideas (not yet scheduled)

- Subtitle/closed caption generation
- Speaker diarization
- In-app video preview with timestamps
- Collaborative summaries sharing
- CLI mode for headless processing
